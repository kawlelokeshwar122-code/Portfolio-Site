Cybersecurity Threat Detection

🛡️ Phishing Website Detection – ELM Classifier

Project Overview

Developed during the internship at JSMINDIA Infosys, this machine learning system automates the detection of malicious phishing websites with a 96.4% classification accuracy. It safeguards users against identity theft and credential harvesting by rapidly analyzing URL characteristics, HTML DOM trees, and domain registration records.

Key Engineering Highlights

  • 30+ Engineered Features: Extracted URL lexical patterns (entropy, token length, symbol count), DOM structure indicators (external script sources, hidden iframes), and WHOIS domain age.
  • Extreme Learning Machine (ELM): Utilized single-hidden-layer feedforward ELM architecture for near-instantaneous training and low-latency inference.
  • Superior F1-Score: Benchmarked against traditional Support Vector Machines (SVM) and Random Forest, surpassing competitors by 3.2% on F1-score.
  • Modular API Component: Packaged as a clean, reusable Python prediction API for frictionless integration with SIEM and web security platforms.

Technologies & Tools

Python Scikit-learn ELM Classifier Pandas NumPy Matplotlib Seaborn WHOIS API

🌿 Real-Time Medicinal Plant Leaf Detection

Project Overview

An end-to-end computer vision solution designed for agricultural scientists, botanists, and healthcare professionals to identify medicinal flora accurately in real time through leaf image analysis.

Key Engineering Highlights

  • MobileNetV2 Transfer Learning: Fine-tuned a pre-trained MobileNetV2 convolutional neural network across a curated dataset of 5,000+ leaf images covering 30+ species.

  • OpenCV Preprocessing: Implemented noise filtering, morphological segmentation, contour extraction, and edge-preserving normalization.
  • Web Interface: Built a responsive web UI allowing users to upload photos or use real-time webcam streams for instant plant identification and medicinal use notes.
